# Plans

One note per plan or decision that is too big for [the roadmap](../roadmap.md). Start from the [plan template](../templates/plan.md).

- Name the file for the work, in lowercase with dashes (for example `floor-generator-steps.md`).
- Set the status line at the top: `proposed`, `active`, `done` or `dropped`.
- Link the plan from the roadmap phase it belongs to, and the roadmap link back. Keep the roadmap as the single list of phases.
- When a plan finishes, record the outcome in its last section and in [the verification log](../verification.md) if it closed an assumption.
