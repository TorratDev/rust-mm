# Progress treemaps (v0)

Two generated SVG maps of the repo. Both are regenerated by script; nothing here is hand-maintained.

| Map | Script | Output |
|-----|--------|--------|
| Code size | `python scripts/progress_treemap.py` | [`treemap.svg`](treemap.svg) |
| Blue function port coverage | `python scripts/port_coverage_treemap.py` | [`port-coverage.svg`](port-coverage.svg) |

## Code size map

Blocks are packages (`crates/sim`, `apps/game`, ...). Cells are `.rs` and `.py` files. Area is non-blank lines.

Limits:
- Lines are a size measure, not progress. A large file is not necessarily more done.
- Only `crates`, `apps`, `tools`, `verification`, `tests`, `fuzz` and `rescue-re` are scanned.
- Generated, vendored and `target/` files are skipped by directory name only; a generated file outside those names would be counted.
- Non-Rust, non-Python sources (`.c`, `.s`, `.java`, shell) are not counted.

## Port coverage map

Units are the functions in [`docs/symbols.md`](../symbols.md) whose type is a C prototype (178 at v0). A function is green when its address appears in `crates/sim/src`.

Limits:
- **Equal weight.** Each cell is one function, not its byte size. Byte sizes need a Ghidra analysis of the ROM, which is not in the repo. A byte-weighted map is the next step.
- **Address reference is a proxy.** A comment that cites an address counts as ported, even if the code only reads the value or calls it. A check that the Rust function implements the Blue routine is not done.
- **Symbols table is the universe.** A Blue function missing from `docs/symbols.md` is invisible to this map. Ported code with no symbols row is also not counted.
- **Overlay grouping by name only.** Overlays are grouped by the `ov_NNNN` prefix in the table; the map does not check that addresses lie inside the overlay.
- **Tags are not used.** `red-hypothesis`, `sdk-hypothesis` and `tentative` names count the same as `blue-verified`.
- **Regeneration is manual.** Nothing runs the script in CI, so the SVG can go stale after `symbols.md` or `crates/sim` changes.
